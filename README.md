# Gaming Enjoyer for Windows

A small tray app for [gamingenjoyer.com](https://gamingenjoyer.com). Pair it with your account and it
keeps the **Installed** marks in your library up to date: Steam games, Steam shortcuts, Xbox/Game Pass,
Battle.net, Ubisoft and EA. It also opens your library in a lightweight window built to sit next to a
running game.

## Download

**[GamingEnjoyer-win-Setup.exe](https://github.com/WebcodingAU/gaming-enjoyer-releases/releases/latest/download/GamingEnjoyer-win-Setup.exe)**
(Windows 10 and 11, 64-bit)

It installs for your user only (no admin), adds a Start menu entry and updates itself. Then pair it from
**Settings → Your PCs** on gamingenjoyer.com.

## Source, privacy and signing

- Source code: [WebcodingAU/steam-sync](https://github.com/WebcodingAU/steam-sync) (MIT license).
  Releases are built from that repository.
- Privacy: nothing is sent before you pair the app. See the
  [privacy policy](https://gamingenjoyer.com/privacy.php) for what it sends after that.
- Code signing: we have applied to the [SignPath Foundation](https://signpath.org) for free code signing
  for open source projects. Until signed releases are available, Windows SmartScreen may warn that the
  installer is from an unknown publisher.

This repository only hosts the installer and update packages.
